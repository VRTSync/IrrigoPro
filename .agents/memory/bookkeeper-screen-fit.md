---
name: Bookkeeper screen fit
description: The accepted desktop width floor and scope for fitting Bookkeeper pages.
---

Bookkeeper desktop pages must fit at browser widths of 1024 px and above with the sidebar expanded. The window and the affected tables should not scroll sideways when the table work is complete; do not hide overflow to meet that requirement. Preserve the existing mobile card layouts.

**Why:** The bookkeeper works on a smaller display. A 1280-wide laptop at 125% Windows scaling can report a 1024 px browser width, so an unscaled 1280 px check is not enough.

**How to apply:** Verify as a bookkeeper with the sidebar expanded. The invoice check must include an expanded row with long line-item descriptions at 1024 × 768, 1280 × 720, and 1366 × 768. Keep row actions reachable from the menu at narrow widths. Do not change role access, server data, or the page padding deferred by the design.
