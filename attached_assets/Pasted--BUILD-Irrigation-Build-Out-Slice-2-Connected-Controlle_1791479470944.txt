## What & Why

After Slice 1 the chips and the zone table agree, but they still don't look connected. A chip is a bare number drawn from a count (`artifacts/irrigopro/src/components/customers/irrigation-controller-grid.tsx:1356`). It says nothing about the zone and goes nowhere when clicked. The table sits behind an expand with no sign of how much of the system is filled in. Randy wants the build-out screen to "feel like all of the inputs are connected to the data underneath."

This slice draws each chip from its zone record, shows on the chip whether that zone is set up, opens that exact zone in one click, and puts one control in charge of adding and removing zones.

**Where this renders.** `IrrigationControllerGrid` (`irrigation-controller-grid.tsx:1714`) is the one component behind both the irrigation profile page (`pages/customers/IrrigationProfile.tsx:544`) and the Irrigation System card on the customer profile (`components/customers/irrigation-system-card.tsx:85`). Both get this change; that is intended (Rule 3, one screen one component).

## Locked decisions (do not relitigate)

1. **A zone is "set up" unless it is still a placeholder (decided).** Placeholder = `name === \`Zone ${zoneNumber}\` && zoneType === "other" && runTimeMinutes === 0 && programId == null && !notes?.trim()`. These are exactly the values Slice 1 inserts. Any real edit makes it set up. One shared predicate, `isPlaceholderZone`, used by server and client.
2. **The stepper is the one control for how many zones a controller has (decided).** Delete the Total Zones input from Edit Details and the Total Zones line from the details panel. "Add Zone" under the table is the same action as the stepper's plus.
3. **The stepper shows whether the tile is collapsed or expanded.** Today it hides when expanded (`:1298`, `!isExpanded`), which is exactly when you are looking at the zones.
4. **Retiring a zone that has data asks first; retiring a placeholder does not.** Retired zones are listed read-only under the table, never in the chips.
5. **Chip colours use existing Tailwind tokens already on this component** — blue for set up (today's chip, `:1358`), gray dashed for placeholder, amber for Needs attention (`isActive === false`, the existing amber at `:838-847`). No new design tokens.
6. Visibility is unchanged: the stepper and Add Zone appear for `canManageControllers`; zone editing for `canEditZones` (`IrrigationProfile.tsx:216-221`).

## Steps

### 1. Shared predicate

New export in `lib/shared/src/irrigation-zones.ts` (re-export from `lib/shared/src/index.ts`):

```ts
export interface PlaceholderZoneFields {
  zoneNumber: number; name: string; zoneType: string;
  runTimeMinutes: number | null; programId: number | null; notes: string | null;
}
/** True while a zone still holds the values Slice 1's reconcile inserts. */
export function isPlaceholderZone(z: PlaceholderZoneFields): boolean {
  return z.name === `Zone ${z.zoneNumber}` && z.zoneType === "other" &&
    (z.runTimeMinutes ?? 0) === 0 && z.programId == null && !z.notes?.trim();
}
```
